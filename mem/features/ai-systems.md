1. **AI Recommendation Engine** — behavior + history + wishlist + purchases → personalized product feeds.
2. **Review Analysis AI** — summarization, sentiment, pros/cons, fake-review detection, trust score.
3. **AI Content Generator** — product descriptions, SEO, highlights, bullets.
4. **AI Customer Reply AI** — seller-side support/review/refund/thank-you replies.
5. **AI Budget Shopping AI** — budget input → optimized product bundles & savings.
6. **AI Camera Shopping AI** — image recognition + visual similarity search.
7. **Smart AI Search Engine** — semantic + voice + NL + personalized search with vector backing.

Implementation preference: Lovable AI Gateway for LLM calls; vector search via Postgres pgvector when backend phase starts.
